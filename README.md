# Learn Yoga Course Design with Phoebe

Six 45-minute sessions on designing a multi-week beginner yoga programme rather than a single class:
what published 12-week programmes actually ran, intake and referral flags, progressions across
weeks, a programme bench that checks an 8-week plan in the browser, mixed-level rooms, and finishing
well with a handover.

- Running case: Juniper Studio, a constructed community studio and its 12-student cohort.
- Bench: `assets/yc-live.js` with data in `assets/yc-data.js` (generated by
  `materials/build_yc_data.py`). `materials/yc_reference.py --json` and `node materials/yc-node.js`
  produce byte-identical canon.
- Not medical advice. Static HTML, no build step: open `index.html`.
